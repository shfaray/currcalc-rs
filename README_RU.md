# currcalc

Конвертер валют в терминале. Курсы берутся из
[frankfurter.dev](https://frankfurter.dev), ключ API и файл конфигурации не
нужны.

[English version](README.md)

## Установка

Нужен Rust 1.85 или новее (edition 2024).

```sh
cargo install --path .
```

Бинарник попадёт в `~/.cargo/bin`. Сборка без установки:

```sh
cargo build --release
./target/release/currcalc usd rub 10
```

## Использование

```sh
$ currcalc usd rub 10
820.00

$ currcalc 10 usd rub
820.00

$ currcalc usd rub
82.00
```

Сумма по умолчанию равна 1 и может стоять до или после пары валют. Регистр
кодов не важен.

В обычном режиме в stdout уходит одно число, поэтому результат удобно
забирать в скриптах:

```sh
total=$(currcalc eur rub 500)
```

Флаг `--json` добавляет курс, дату и источник:

```sh
$ currcalc --json usd rub 10
{"amount":10.0,"date":"2026-11-22","from":"USD","rate":82.0,"result":820.0,"source":"frankfurter.dev","to":"RUB"}
```

`result` округляется до `--precision`, а `rate` содержит исходное значение из API.
Курсы в примерах приведены на 22 ноября 2026 года.

## Форматы суммы

| Ввод | Значение |
| --- | --- |
| `10` | 10 |
| `321.32` | 321.32 |
| `51,51` | 51.51 |
| `1 234,56` | 1234.56 |
| `1,234.56` | 1234.56 |
| `1.234,56` | 1234.56 |
| `1,234,567` | 1234567 |

Пробелы, включая неразрывные, игнорируются. Если в строке есть оба
разделителя, десятичным считается последний, а другой разделяет разряды.
Разделитель, который повторяется без второго, всегда разделяет разряды, и в
каждой группе должно быть по три цифры, поэтому `1,2,3` отклоняется, а не
превращается в другое число. Отрицательные суммы не принимаются.

## Список валют

```sh
$ currcalc list
AED   United Arab Emirates Dirham
AFN   Afghan Afghani
...
$ currcalc list rub
AWG   Aruban Florin
BYN   Belarusian Ruble
RUB   Russian Ruble
```

`list` ищет подстроку в коде или названии, поэтому `rub` находит и Aruban
Florin. По умолчанию в списке 161 фиатная валюта, которую отдаёт API. Флаг
`--all` добавляет крипту и металлы (BTC, XAU и другие), у таких строк
появляется колонка с типом. `--json` печатает массив объектов с полями `code`,
`name`, `symbol` и `type`.

## Флаги

| Флаг | Описание |
| --- | --- |
| `--json` | Печатать JSON вместо числа |
| `--precision <N>` | Знаков после запятой в результате, от 0 до 8, по умолчанию 2 |
| `--date <YYYY-MM-DD>` | Взять курс, опубликованный в эту дату |
| `--no-cache` | Не читать кэш, запросить свежий курс |
| `--offline` | Не обращаться к сети, брать только кэш |

Флаги можно ставить до или после валют.

Исторические курсы доступны для любой даты, которая есть в API для данной
пары. Дата вне покрытия возвращает ошибку. Для примера `--date 2024-05-15`
даёт 91.38.

## Кэш

Курсы лежат в `$XDG_CACHE_HOME/currcalc` (`~/.cache/currcalc`, если
переменная не задана), по одному небольшому JSON-файлу на пару и дату.
Текущий курс считается свежим в течение часа, исторический не устаревает, а
список валют живёт неделю.

Если запрос не удался, а в кэше есть старая запись, currcalc пишет
предупреждение в stderr и берёт её. `--offline` вообще не ходит в сеть:
отдаёт кэш даже старше TTL, а если кэша нет, завершается ошибкой.
`--no-cache` игнорирует сохранённые записи, поэтому вместе с `--offline`
читать будет нечего.

## Коды выхода

| Код | Значение |
| --- | --- |
| 0 | Успех |
| 1 | Ошибка конвертации: неизвестная валюта, нет сети и нет кэша |
| 2 | Неверные аргументы или их отсутствие (печатается справка) |

Результат идёт в stdout, ошибки в stderr.

## Разработка

```sh
cargo test
cargo clippy --all-targets -- -D warnings
cargo fmt --check
cargo test -- --ignored
```

Последняя команда обращается к живому API. Остальные тесты работают без
сети: CLI-тесты кладут кэш во временный каталог и запускают бинарник с
`--offline`.

## Источник данных

Frankfurter собирает справочные курсы центральных банков и других
официальных источников. Это среднерыночные значения, которые обновляются раз
в день или несколько раз в день, а не биржевые котировки. По некоторым
валютам история есть с 1948 года.

Если используете результат в отчёте, будет приятно увидеть строку вида
«Exchange rates: Frankfurter (frankfurter.dev)», но это не требование.
